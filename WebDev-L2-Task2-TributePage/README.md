# Mohamed Salah Tribute Page

## Oasis Infobyte Internship

**Oasis Infobyte – Web Development & Designing Internship**  
**Level 2 – Task 2: Tribute Page**

## Project Overview

Mohamed Salah Tribute Page is a responsive single-page website dedicated to the Egyptian footballer Mohamed Salah. The page presents a short biography, a career timeline, major achievements, and a featured quote in a clean and accessible layout.

## Live Demo

[View the live project](https://amirahassann.github.io/OIBSIP/WebDev-L2-Task2-TributePage/)

## Features

- Page title with Mohamed Salah's name and tagline
- Prominent hero image
- Biography section with multiple paragraphs
- Career timeline with important milestones
- Achievements section
- Styled quote block
- Multiple background colors across sections
- Serif typography for headings and sans-serif typography for body text
- Clean semantic HTML structure
- Accessible labels and alt text
- Hover and focus states
- Reduced-motion accessibility support
- Responsive layout for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript is not required and is not used for the main functionality

## Design Highlights

- Strong visual hierarchy with large serif headings and readable body text
- Section-based layout with distinct background colors
- Timeline and achievement cards styled for clarity and balance
- Subtle hover feedback to improve interactivity
- Accessible focus treatment for keyboard users

## Responsive Design

The layout uses CSS Grid and responsive media queries to adapt smoothly across desktop, tablet, and mobile screens. Content reflows into a single-column layout on smaller screens, while spacing and image sizing remain readable and balanced.
